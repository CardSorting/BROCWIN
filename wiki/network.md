# Winsock, virtual networking and original services

[Wiki home](README.md) · [Implementation and tests](generated/INDEX.md#network)

Original client code supplies the game protocol. Wasm Winsock provides virtual socket state, event signaling and supported overlapped operations. `local_server_wire.js` carries `vln/1` frames over WebSocket; `network.py` relays bytes only to fixed local original services. UDP targets are resolved from owned server processes and local interfaces. Each browser session owns its native sockets. Guest listeners take precedence over external routing.

`theseus/runtime.py` starts/inspects the isolated native stack and retains process identity. SQL is local at `127.0.0.1:15433`. Login, channel selection, character loading, dungeon transitions and progression depend on the original services. Per the user's 2026-10-10 clarification, servers and SQL remain native and locally maintained apart from the port. That is the intended deployment boundary. The browser client must interoperate with them; server porting is outside scope.

## Verified scope

Existing tests cover real compiled Wasm Winsock through the shipped JS wire, WebSocket and native TCP; large duplex transfers, credit/backpressure, EOF/loss, event rearming, fragmented buffers and event-based overlapped I/O. Datagram tests preserve vectors as one UDP packet, zero-length packets, source identity and session isolation. A native-port self-probe is reflected only for the owning session and its mapping. No acknowledgements or game messages are synthesized.

Socket IOCP, completion-routine paths, datagram scatter receive, broader peer multiplayer and internet deployment remain incomplete/unverified. Passing byte-transfer tests cannot prove the application handled a specific ACK.

## Reproduction and diagnosis

Replay login → character → Ruben → options open/close in the same executable. Retain request timing, actual send/receive counters, original pending vector, executing worker state and server logs. If breakpoints are necessary, label their timing impact, clear them before unrelated gameplay, and also run without them. Do not insert fake ACKs, suppress the original timeout, or modify server rows to force progress.

`VSOCK` word 12 (+48) is the receive **head/read offset**; word 13 (+52) is readable length. Advancing head is not a growing backlog. Empty relay queues and consumed TCP bytes do not identify which original game event was consumed. Billing-query errors occur in passing and failing runs; correlation is not an established cause. Use the existing bounded diagnostics before considering further instrumentation.
