# 0005 — Shared wire consumption and receive credit

[Wiki home](../README.md) · [Networking](../network.md) · [Issues](../issues.md)

Date: 2026-10-11 UTC. Contributor: Codex /root, no delegated agents. Original native servers, SQL and game protocol remain unchanged. Acceptance is incomplete.

The [sealed 000646 replay](../../reports/browser/20261011T000646Z/review.json) passed original login, saved-character selection, Ruben movement/menus, A/S skills and the first Tree of El area. In area two, the browser WebSocket closed at 00:33:55 UTC. The original no-response dialog appeared; acknowledging it led to a measured main-thread host exit with code 0. SQL retained only ordinary gameplay gains of 12 EXP and 31 ED. Victory, revival, rewards and return were not reached. The empty input queue, pending ACK 172 and consumed socket bytes do not establish the failed exchange's cause. The old wire did not preserve its close code or reason.

Bounded inspection found two separately reproducible client transport races. [The regression](../../tools/wine-assembly/test/test-vlan-shared-pump.js) runs two real Wasm instances against the same memory and forces an interleaving at a host import. One instance can copy a queue head, another consume it, and the first deliver its stale copy. Separately, another receive can reuse credit while its first sender is parked. Both old-module controls return 12,288 bytes of credit for only 8,192 wire bytes; the first also duplicates 4,096 payload bytes. This can violate the existing relay's credit contract, but does not prove the cause of the historical live close.

[09d-winsock.wat](../../tools/wine-assembly/src/09d-winsock.wat) now claims nonblocking process-wide pump ownership across peek/delivery/commit. Contending instances return without spinning, allowing the main thread to service a parked worker's RPC. Receive credit uses atomic accumulation and exchange before sending; a refused send atomically restores its claimed debt. No capacity, timeout, ACK or game packet is changed. The existing process-state region has a spare ownership word; its size and placement remain unchanged.

The existing [browser wire](../../browser/local_server_wire.js) now retains local closure cause and the WebSocket close event. The [byte relay](../../browser/network.py) logs bounded transport rejection/header/window metadata at closure, without game payloads. This will distinguish credit rejection, browser validation and other transport loss on the next original replay.

[Validation](../../reports/network-concurrency-20261011T005500Z/validation.json) preserves failing controls, main/compatibility passes, backpressure retry, source/module/patch identities and regression results. Canonical build, stream wire, Winsock, idle pump, real Wasm-to-TCP/UDP and worker overlapped-I/O checks pass. An older startup-data test expects 64 sockets; both preserved control and candidate report 128 and fail identically. That test was not changed.

The [sealed 010733 replay](../../reports/browser/20261011T010733Z/review.json) now verifies one complete Tree of El victory, original rewards and return to Ruben. Native disconnect statistics confirm one win, two completed attempts and 78 dungeon ED (62 from victory, 16 from the later failed attempt). Saved EXP rises from 52,550 to 58,218 and ED from 3,114 to 3,192. All 242 frozen sources, two modules and patch match; 125 manual/final images were reviewed.

[The retained failure](../../reports/browser/20261011T010733Z/loading-failure.json) distinguishes this from relay rejection: the client requested transport closure after its worker timeout, code 1005, with no relay rejection. The last healthy arena count was 752/1024. It does not close the old transport failure or exercise the repaired arena boundary.
