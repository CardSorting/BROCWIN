## Memory contract

Guest virtual pages can have discontiguous physical backing. A successful translation of the first byte does not authorize a contiguous copy across a page boundary. Use the existing guest-page copy/clear/gather/scatter helpers; validate overflow, null/sentinel translations, buffer lengths and allocation ownership before publication. Renderer snapshots must own bytes before guest scratch reuse. Never keep a borrowed scratch pointer as a durable texture/geometry record.

Allocated runtime region bases come from the WATX region allocator. Read `lib/region-map.generated.js` or `node tools/region-layout.js`; do not duplicate current addresses in new code. The original game's pointers also change between runs. A prior capture's heap address is a discovery aid, not a stable API.

The heap's four-byte header retains its aligned extent and uses low-bit states 0 for normal live, 1 for GlobalAlloc live and 2 for free. Other combinations remain malformed. Only an atomic live-to-free winner may publish a free-list link and subtract arena live bytes. Free-list size arithmetic masks the state; newly returned allocations have the appropriate live state. Keep exact Global-handle boundary checks, strict validation of live opaque objects and bounded rejection of corrupted lists. No additional region or cache owns this state.
