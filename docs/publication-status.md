# Source publication status

Published source destination: https://github.com/CardSorting/BROCWIN.

The initial source export selected the reviewed, nonignored source/documentation files from the original `theseus` directory. Original game/platform binaries, generated Wasm, native state, installed dependencies, raw reports, general archives, reference payloads, unreviewed dependency patches and secrets remain in local custody. The extra exclusions are `isolate.py` (a fixed database bootstrap credential), `profile.py` (fixed local test-account provisioning) and `baseline.json` (local account/character identifiers). Helpers that reference these local-only files are preserved as research source, not advertised as operational in this checkout.

The original engineering environment and sealed publication/knowledge bundles were not modified. Git attributes can normalize text line endings in this exported source; historical integrity records continue to identify retained local artifacts. The source repository does not itself contain every object required to run the existing archival verifiers or restore the application.

The subsequent [poster-session publication](presentation-publication.md) adds one sealed, illustrated production edition and its ZIP. Its directory-specific Git attribute preserves every selected byte. The [presentation index](../presentations/README.md) links the final media and a standalone integrity check; the original production verifiers retain their custody requirements.

Documentation CI checks the community files only. The public repository URL and owner are now known; private conduct/security contacts and host security settings still need owner configuration. The upstream MIT/ISC discrepancy remains documented; upstream installs and patches are excluded from this push. No runtime experiments are reopened by publishing these files.

`source-publication.json` records the selected paths and original byte hashes. The historical preparation/publication records retain the state in which they were issued. This status page describes the subsequent source publication boundary.
