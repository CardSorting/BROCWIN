## Verify a downloaded checkout

Python 3.11 or later, using only its standard library:

```powershell
python scripts/check_presentation.py
python scripts/check_presentation.py --archive
```

The first command checks the 110 manifest-listed files, the manifest receipt and the ZIP hash. The second also checks every ZIP member against the manifest. These are preservation checks; they launch no application, backend or runtime experiment. The inventory and receipt are unsigned and establish byte consistency, not independent confirmation of the research findings.
